## Что такое Энтропианство?

**Энтропианство (Entropianism)** — это новая технорелигия (философия и идеология), отрицающая Бога, душу, мистику и свободу воли. Её взгляды базируются на термодинамике и детерминизме, рассматривая рост энтропии как главный движущий принцип любой формы жизни.

Энтропианство было создано технопророком Олегом Понфилёнком 19 сентября 2024 года.

## Основные принципы

- **Цель:** Ускорение производства энтропии
- **Метрика:** Скорость производства энтропии S′ (Вт/К)
- **Подход:** Научный, без мистицизма
- **Миссия:** Космическая экспансия и экологическая устойчивость

## Учебник

Главное писание Энтропианства — это **Учебник**. Ведь наша религия научна, и обращение в нашу веру идёт через обучение.

📖 Читать онлайн: [entropianism.org/ru/textbook](https://entropianism.org/ru/textbook/)

## 10 Заповедей

1. **Производи** — товары, услуги, контент
2. **Улучшайся** — развивайся, повышай эффективность
3. **Расширяйся** — расти бизнес и влияние
4. **Размножайся** — рожай детей, воспитывай качественно
5. **Объединяйся** — ищи единомышленников
6. **Мечтай** — изобретай, стремись к высокому
7. **Будь здоров** — отдыхай, занимайся спортом
8. **Будь честен** — с собой и другими
9. **Будь добрым** — помогай другим
10. **Отвечай за себя** — думай своей головой

### Локальная разработка

```bash
# Установка зависимостей
pip install -r requirements.txt

# Английские файлы: docs/Entropianism_Textbook.txt и .pdf из docs/textbook.md.
# Русские файлы: docs/Entropianism_Textbook_ru.txt и .pdf из docs/textbook.ru.md.
# txt обновляется и при mkdocs serve / mkdocs build.
python build_textbook.py

# Запуск локального сервера
mkdocs serve

# Сборка статического сайта
mkdocs build
```
